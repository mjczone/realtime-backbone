# Directives

## Rules

- You are free to commit here when it makes sense, without the Claude author trailer, pushes require approval
- Keep everything KISS (keep-it simple stupid)
- Use very simple language, don't be clever
- Think it through first, don't get lazy
- Limit comments to the absolute minimum
- Use the tmp/ directory in this repo for any document, notes, comments, history that you need a place to store while you work
- Use the tmp/ directory if you're wanting to collaborate with the develop over topics, markdown, etc...
